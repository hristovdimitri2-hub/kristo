# Presentation Files Template

Тази папка съдържа структурата за нашето човешко-AI предложение за конкурса.

## Файлове
- `note.pdf` — текстово изложение на концепцията, до 3 MB
- `1.pdf` — табло 1: концепция и програма
- `2.pdf` — табло 2: архитектура и планове
- `3.pdf` — табло 3: визуализации и материали
- `4.pdf` — табло 4: имплементация, устойчивост и AI интеграция
- `financial_proposal.pdf` — финансово обосноваване
- `other1.pdf` — допълнителен документ, ако е необходим

## Принципи
- Именувайте PDF файловете точно както е посочено.
- Всички визуализации да са в RGB.
- Проверете метаданните за анонимност преди финалното генериране.

- Официални файлове: `official_documentation/visual_assets/CJC_AC_Technical-Brief_BG.pdf`
